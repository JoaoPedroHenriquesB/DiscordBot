Um bot para Discord desenvolvido em Python utilizando a biblioteca discord.py. Este bot oferece diversas funcionalidades para melhorar a experiência no seu servidor.

Funcionalidades
Comandos de Moderação:

!kick - Expulsa um membro do servidor.

!ban - Bane um membro do servidor.

!clear - Limpa uma quantidade especificada de mensagens.

Comandos Úteis:

!ping - Verifica a latência do bot.

!userinfo - Mostra informações sobre um usuário.

!serverinfo - Mostra informações sobre o servidor.

Diversão:

!meme - Envia um meme aleatório.

!coinflip - Cara ou coroa?

!roll - Rola um dado.

Pré-requisitos 📋
Python 3.8 ou superior

Biblioteca discord.py

Um token de bot do Discord
